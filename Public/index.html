Frame-Generator-API

Ecossistema web para carregar modelos de IA, analisar metadados GGUF, planejar geração/aprimoramento de quadros (imagem, vídeo, jogo), administrar engines, repacks, ferramentas, usuários e tarefas — com API lógica central e núcleo no navegador.

Modelos & GGUF

Análise real de metadados GGUF no navegador, registro, compatibilidade e quantização (análise/planejamento) com execução delegada a runtime compatível.

Geração de quadros

Motores unificados para imagem, vídeo e jogo: planejamento, análise e integração com engines/provedores externos quando necessários.

Repacks & Ferramentas

Manifests JSON validados, registro de ferramentas/repacks e administração modular integrada à API lógica e ao painel.

Hospedagem estática no GitHub Pages (modo demonstração/local). Inferência e processamento pesado dependem de engines, runtimes ou backends externos compatíveis configurados — sem simulação de resultados.
