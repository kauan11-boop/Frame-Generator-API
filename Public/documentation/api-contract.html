Contrato lógico /api/v1

Uma única API que controla tudo: JSON de entrada/saída, estados explícitos e guard de permissões por namespace (configs/permissions.json). No modo demo os handlers locais executam análise/planejamento reais; operações de execução retornam requires-runtime/requires-provider. Em local/remote, endpoints remotos são atendidos pelo baseUrl configurado.
