Arquitetura de diretórios (v2)

Reconstruída com limites rígidos: src ≤ 10 pastas e Public ≤ 10 pastas (limite do requisito: 20). Cada pasta tem um único propósito; carregadores e lógica em src/, interface administrada em Public/.

Frame-Generator-API/
├── index.html              # redireciona ao shell
├── package.json / LICENSE / README.md
├── configs/                # JSON único editável (6 arquivos)
│   ├── api.json            # contrato /api/v1 (namespaces, endpoints, permissões)
│   ├── models.json         # catálogo de modelos
│   ├── generators.json     # gêneros + orçamentos de pixels
│   ├── repacks.json        # repacks multi-ferramenta
│   ├── permissions.json    # papéis, matriz, usuários padrão
│   └── settings.json       # tema, modos, backends, runtimes
├── src/                    # NÚCLEO (10 pastas)
│   ├── core/               # kernel, bus, states (máquina de estados)
│   ├── config/             # loader/validador de configs
│   ├── models/             # gguf.js (parser binário), quantizer.js, registry.js
│   ├── runtime/            # detect.js, tfjs.js, transformers.js
│   ├── api/                # router.js (/api/v1), lmstudio.js, client.js
│   ├── generators/         # planner.js (jogos/imagem/vídeo), perf.js (FPS + pixels)
│   ├── repacks/            # manager.js (multi-ferramenta em 1 comando)
│   ├── security/           # users, roles, session (UI-level)
│   ├── storage/            # store.js (kv) + fs.js (VFS IndexedDB)
│   └── shell/              # public-api.js → window.FGUA
├── Public/                 # INTERFACE (10 pastas)
│   ├── desktop/            # shell Win11 (index.html, shell.js, wm.js)
│   ├── apps/               # 12 apps + common.js
│   ├── styles/             # win11.css (Fluent) + apps.css
│   ├── assets/             # wallpapers SVG + icons.svg (sprite Fluent)
│   ├── documentation/      # 7 páginas standalone
│   ├── presets/            # default-presets.json
│   ├── templates/          # job-template.json + master-prompt-integration.md
│   ├── manifests/          # sample-repack.json
│   ├── locales/            # pt-BR.json, en-US.json
│   ├── workers/            # gguf.worker.js
│   └── dashboard.html      # dashboard standalone
├── tests/                  # 5 suítes + run-all
└── scripts/                # serve.mjs (:4173) + ci.mjs

Fluxo de boot

index.html → shell Public/desktop/index.html → shell.js importa src/shell/public-api.js → kernel.boot() carrega as 6 configs JSON, detecta capacidades (WebGPU/WebGL/WASM/WebCodecs), restaura sessão e monta o roteador /api/v1 → splash → lock screen → desktop.

Princípios

1) JSON como fonte única de dados editável. 2) Estados explícitos em toda operação — nada simulado. 3) Guard de permissões por namespace. 4) Parser GGUF lê somente o header (orçamento 32 MB), nunca o corpo. 5) Import absolutamente relativos (import.meta.url) — funciona em qualquer subcaminho do GitHub Pages.
