Comandos

Projeto (npm)

npm install          # dependências (apenas desenvolvimento; zero runtime deps)
npm run serve        # servidor local → http://localhost:4173
npm run ci           # CI completa: valida configs, manifests, testes e referências
npm run test         # testes unitários (parser GGUF, roteador, quantizador)
npm run validate     # valida apenas configs/*.json

Publicação (GitHub Pages)

git init
git add .
git commit -m "FGUA v2 — versão definitiva"
git remote add origin https://github.com/kauan11-boop/Frame-Generator-API.git
git push -u origin main
# Settings → Pages → Deploy from branch → main → / (root)
