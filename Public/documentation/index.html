Documentação do FGUA v2

O Frame-Generator-API (FGUA) é um núcleo web modular com shell de sistema operacional Windows 11 para análise/registro de modelos, inspeção de capacidades e planejamento de geração/aprimoramento de quadros sob o contrato lógico /api/v1/*. Runtime HTML5 + CSS3 + JavaScript (ES Modules), hospedado no GitHub Pages como site estático.

Arquitetura

Diretórios, subsistemas e fluxos (SRC ≤ 10 · PUBLIC ≤ 20).

Contrato /api/v1

16 namespaces, endpoints, estados e permissões.

Comandos

npm, terminal FGUA e LM Studio.

Limites reais

O que o navegador faz e o que exige runtime externo.

Master Prompt IA

Prompt de integração para modelos/agentes de IA.

Recursos do sistema

Área de trabalho: /Public/desktop/index.html · Dashboard standalone: /Public/dashboard.html · Configs: /configs/api.json
