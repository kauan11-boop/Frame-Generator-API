# Archive (legado)

Esta pasta contém artefatos legados/históricos preservados no repositório.

- **Não é fonte de verdade** do runtime ativo, dos contratos atuais, nem da documentação principal.
- O código e a UI ativos devem consumir `src/`, `configs/`, `Public/` e os contratos/documentação atualizados na raiz/`Public/documentation/`.
- Arquivos em `archive/_legacy_old` e `archive/Legacy` podem conter estruturas, paths e contratos antigos que não correspondem à implementação atual.

Se for necessário reaproveitar algo do legado, migrar/validar explicitamente para a estrutura e contratos atuais antes de integrar.
