Servidor MCP local — stdio

Modo recomendado para hosts MCP que iniciam o processo localmente. Não exige IA no runtime.

npm install
npm run mcp

Configure o host MCP para iniciar node /caminho/Frame-Generator-API/server/index.js com o diretório de trabalho na raiz do projeto.

Servidor MCP HTTP

Endpoint local compatível com Streamable HTTP.

npm run mcp:http
# MCP: http://127.0.0.1:3333/mcp
# Health: http://127.0.0.1:3333/health

O bind padrão é loopback. Acesso remoto exige token, allowlist e proxy TLS configurados.

Cliente MCP

O módulo server/client.js conecta a servidores externos por Streamable HTTP, lista tools/resources/prompts e permite chamadas explícitas.

import { connectMcpServer } from './server/client.js';

const remote = await connectMcpServer({
  url: 'https://servidor.example/mcp'
});
const tools = await remote.listTools();
await remote.close();

Ferramentas disponíveis

  • fgua_system_status — estado e diagnóstico
  • fgua_api_contract — namespaces do contrato /api/v1
  • fgua_modules_list — inventário de módulos
  • fgua_catalog_read — catálogos JSON
  • fgua_ai_status — configuração opcional de IA sem expor segredos
  • fgua_pipeline_validate — validação estrutural sem executar etapas

Resources: fgua://system/status, fgua://api/contract, fgua://catalog/models, fgua://catalog/generators.

Prompt: fgua_pipeline_design.
