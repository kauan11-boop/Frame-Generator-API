# frames

Domínio de geração e orquestração de quadros.

- Modos: `storyboard`, `video_frames`, `data_panels`, `composite`.
- Orquestrador e estados de job: `../api/v1/frames/index.json`.
- Templates e schemas de cena/painel: `../api/v1/frames/templates.json`, `../schemas/frame-job.schema.json`.
- Resultados/índices: `../data/frames/`.

Criação/controle de jobs é realizado via adapter/backend configurado.
