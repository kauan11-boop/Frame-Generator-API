# interface

Camada de interface/visualização da plataforma.

- **Interface web principal (pública):** `../../public/` (landing em `index.html`, dashboard em `dashboard.html`, organizada em `css/`, `js/`, `assets/`).
- A interface consome a API estática em `../api/v1/` e utiliza o SDK/contratos em `../sdk/` e `../schemas/`.
- Conteúdos de UI não ficam nesta pasta de `src/` (scripts de automação em `../scripts/` permanecem separados e sem alterações).
