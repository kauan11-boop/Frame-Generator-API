Frame-Generator-API

API unificada estática para GitHub Pages: modelos de IA (metadados GGUF + carregador), geração de quadros (storyboard, vídeo, dados/UI), pacotes autoajustáveis, comandos JSON, Repack e prompt de integração.

Abrir painel Admin Discovery (JSON) Prompt de integração

Endpoints principais: /api/v1/models/index.json, /api/v1/frames/index.json, /api/v1/packages/index.json, /api/v1/commands/index.json, /api/v1/repack/index.json.

  • Leitura estática no Pages; escrita/execução via adaptadores externos (HTTP, OpenAI-compatible, Cloudflare Worker, WASM experimental).
  • Repack: pipeline auditável (scan→diff→plan→simulate→apply→verify), sem mutação oculta de código-fonte.
