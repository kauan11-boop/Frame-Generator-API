Instalação local

O painel é estático (GitHub Pages). As ações exigem o bridge local; ele não roda no GitHub.

npm install
npm run bridge     # http://127.0.0.1:4174
npm run mcp        # servidor MCP stdio para o agente

Registre o MCP no OpenCode apontando para mcp-server/src/index.js. Veja o README.

Integrações e limites

O que funciona

  • Orquestração de ferramentas do MCP REA por catálogo.
  • Relatórios de RE com Evidence IDs e hash do arquivo.
  • Reparo/transpilação com testes reais como reward.
  • Presets e prompts editáveis pelo painel.

Limites reais

  • GitHub Pages é estático: não hospeda MCP nem executa código.
  • WASM é alvo de compilação, não interpretador de C#/Python/NodeJS.
  • O bridge escuta apenas em 127.0.0.1.
  • Primeira execução de modelo exige LM Studio ativo (padrão :1234).

Nenhum segredo deve ser colocado aqui: o painel é público e o arquivo é versionado.
