Frame-Generator-API

Núcleo web modular para análise e registro de modelos (incluindo metadados GGUF no navegador, sujeito a limites), inspeção de capacidades/engines/provedores, gerenciamento de configurações públicas e integração por contrato (/api/v1).

Esta interface é honesta sobre o que está disponível: em hospedagem estática não há servidor REST nativo. Inferência, quantização/conversão efetiva e processamento pesado de imagem/vídeo não são simulados e dependem de backend, engine ou provedor compatível configurado.

O dashboard inclui ferramentas de integração (payload e cliente WebSocket opcional), estúdio Discord para geração de templates com simulação local na interface e demo React no navegador — sempre com estados e limites explícitos.

Por onde começar

1. Verificar ambiente

Abra o dashboard para ver status do núcleo, diagnóstico de configurações, capacidades do navegador (WebGPU, WebCodecs, WASM, etc.) e recursos da sessão.

2. Explorar recursos

Consulte modelos, geradores, engines, provedores, presets, templates, manifests e configurações públicas expostos pelo projeto.

3. Integrar e configurar

Na aba Integração, configure backend compatível (sessão), exporte o payload e utilize o cliente WebSocket opcional para endpoints externos.

4. Gerar artefatos e integrar IA

Use o estúdio Discord para templates/simulação local, a demo React e o master prompt/documentação para conectar agentes e pipelines ao contrato real.

Verificação rápida do núcleo (navegador)

Opcional: inicializa o núcleo nesta página para confirmar carregamento de módulos e configurações. Para uso completo, utilize o dashboard.
